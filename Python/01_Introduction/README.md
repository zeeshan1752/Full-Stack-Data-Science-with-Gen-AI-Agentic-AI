# Python Introduction

## What is Python?

Python is a **high-level**, **interpreted**, and **general-purpose** programming language. It is easy to learn because of its simple and readable syntax. Python is widely used in Data Science, Machine Learning, Artificial Intelligence, Web Development, Automation, and many other fields.

---

## Father of Python

Python was created by **Guido van Rossum** and was first released in **1991**.

---

## Features of Python

- Simple and easy to learn
- Easy to read and write
- High-level programming language
- Interpreted language
- Open source
- Platform independent
- Object-oriented programming support
- Large standard library
- Huge community support
- Dynamically typed

---

## Applications of Python

Python is used in many areas, such as:

- Data Science
- Machine Learning
- Artificial Intelligence (AI)
- Web Development
- Automation and Scripting
- Data Analysis
- Desktop Applications
- Game Development
- Cyber Security
- Cloud Computing

---

## IDE (Integrated Development Environment)

An **IDE** is software that provides everything needed to write, run, test, debug, and manage programs in one place.

### Features of an IDE

- Code Editor
- Syntax Highlighting
- Auto Completion (IntelliSense)
- Debugging
- Integrated Terminal
- Project Management
- Extension Support

### Popular IDEs / Code Editors for Python

- Visual Studio Code (VS Code)
- PyCharm
- Jupyter Notebook
- JupyterLab
- Spyder
- IDLE

---

## Installation

### Install Python

Download and install the latest version of Python from the official website.

> https://www.python.org

### Install Visual Studio Code

VS Code is a lightweight and popular code editor used for Python development.

> https://code.visualstudio.com

### Install Anaconda

Anaconda is a Python distribution mainly used for Data Science, Machine Learning, and AI. It comes with Python, Jupyter Notebook, and many useful libraries pre-installed.

> https://www.anaconda.com

---

## Check Python Version

Open Command Prompt or Terminal and run:

```bash
python --version
```

or

```bash
python3 --version
```
