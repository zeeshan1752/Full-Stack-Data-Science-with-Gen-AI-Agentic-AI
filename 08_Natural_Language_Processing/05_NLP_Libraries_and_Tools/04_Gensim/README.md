# Gensim

Gensim provides implementations for word embeddings, document similarity, and topic modelling. This folder focuses on library usage; the main conceptual explanation for Word2Vec stays in Text Representation.

## Existing Word2Vec practice

- [Word2Vec lesson](../../02_Text_Representation/05_Word2Vec/README.md)

- [Word Embeddings overview](../../02_Text_Representation/04_Word_Embeddings/README.md)

Install Gensim with:

```bash
python -m pip install --upgrade gensim
```

The notebook's small corpus demonstrates the API only; it is not enough data for general-purpose embeddings. Its code was not rerun during this folder reorganization.
