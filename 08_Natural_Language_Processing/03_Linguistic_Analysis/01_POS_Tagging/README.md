# Part-of-Speech Tagging

POS tagging assigns a grammatical category, such as noun, verb, adjective, or adverb, to each token in context. Tag sets and predictions depend on the language and tagging model.

## Existing evidence

The preserved [NLTK practice notebook](../../01_Preprocessing/02_Tokenization/nltk_cross_topic_practice.ipynb) includes POS tagging. This standalone companion uses NLTK and has not been executed.

## Setup and run

Install NLTK with python -m pip install nltk. If NLTK requests data resources, use the official [NLTK data guide](https://www.nltk.org/data.html); resource names can depend on the NLTK version.

The output is a model prediction, not a guaranteed grammatical analysis. See [NLTK notes](../../01_Preprocessing/02_Tokenization/README.md#nltk) and [NER](../02_NER/README.md).
