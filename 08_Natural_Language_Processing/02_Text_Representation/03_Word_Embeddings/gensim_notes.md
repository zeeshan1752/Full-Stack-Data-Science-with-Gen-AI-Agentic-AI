# Gensim

Gensim provides models for word embeddings, document similarity, and topic modeling.

## Existing material

- [Word2Vec lesson](word2vec_notes.md)
- [Word2Vec notebook](word2vec_gensim.ipynb)

The lesson uses a small corpus to demonstrate the Gensim API. It is not enough data for meaningful general-purpose embeddings. The notebook contains saved outputs; its code was not rerun during this folder reorganization.

Install Gensim with python -m pip install --upgrade gensim. The other Gensim topic folders are planned.
