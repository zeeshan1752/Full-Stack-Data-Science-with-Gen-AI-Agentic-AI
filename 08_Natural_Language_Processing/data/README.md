# Shared Data

Shared examples and small datasets belong here so topic folders can reuse them without making copies.

- [sample_texts.txt](sample_texts.txt) contains examples for preprocessing and library comparisons.
- [restaurant_reviews.tsv](restaurant_reviews.tsv) is a shared synthetic dataset for sentiment analysis examples.
- The spam project can use the [UCI SMS Spam Collection](https://archive.ics.uci.edu/dataset/228/sms+spam+collection). Download it, extract SMSSpamCollection, and place the file here as sms_spam.tsv. It is not included in this repository; UCI lists it under CC BY 4.0.
